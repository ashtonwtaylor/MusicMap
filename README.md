# Music Map

An interactive world map which allows users to listen to music from the selected region of the world.

The map will be implemented using the JavaScript library Leaflet.

GeoJSON data acquired from: https://github.com/datasets/geo-boundaries-world-110m/blob/main/countries.geojson

# Planned Features
- Login to save favorited stations
- Toggleable music visualizer

# UI/Bug Fixes
- Move player bar to box below station list
- Prevent user clicks while a station is loading to minimize playback errors
